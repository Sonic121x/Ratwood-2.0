# 指南浏览器

服务器启动后，首位玩家加入大厅时会异步加载指南目录，加载成功后，拥有动作栏的玩家可以打开「指南浏览器」。目录未配置或首次加载失败时，按钮不可用，管理员可手动重载。BYOND 516 及以上可在游戏内阅读，也可用右上角按钮外部打开。较旧的客户端在确认后用外部浏览器打开当前指南。

`OOC → 切换指南按钮显示` 可显示或隐藏动作栏上的按钮，这项设置保存在玩家偏好中。隐藏按钮后仍可用 `OOC → 打开指南浏览器` 打开指南。

在服务器配置中设置 `GUIDE_CATALOG_URL`，值为受信任的公开 HTTPS JSON 地址。示例目录如下。

```json
{
  "version": 1,
  "wiki_base_url": "https://wiki.example.org/wiki",
  "tree": [
    {
      "kind": "category",
      "id": "start",
      "label": "入门",
      "children": [
        {
          "kind": "page",
          "id": "controls",
          "label": "操作指南",
          "title": "操作指南"
        }
      ]
    }
  ]
}
```

`title` 是 Wiki 页面标题。目录默认选择树中第一篇页面。若 Wiki 拒绝内嵌，仍可用外部浏览器阅读。

具有服务器权限的管理员可使用「重新加载指南目录」，输入当前地址或另一个 HTTPS 地址。重载成功后已打开的指南窗口会关闭，重新打开时会保留仍有效的页面选择。请求失败或目录无效时，已加载的目录继续可用。通过指令更换的地址仅在当前运行期间生效，重启时读取 `config.txt`。
